API Reference

Pipeline API endpoints — base URL: http://localhost:8000

GET/health
Health check — returns service status
GET/analytics/data
All analytics records as JSON array
GET/analytics/summary
Aggregated stats — total videos, platforms, avg quality
GET/analytics/insights
AI-generated insights from recent analytics
POST/pipeline/research
Start yt-pipeline research job. Body: {"topic": "...", "max_videos": 20}
GET/pipeline/research/status/{run_id}
Poll research job status: running | done | error
GET/pipeline/research/result/{run_id}
Get research results when status = done
POST/voiceover/generate
Generate voiceover from script dict
POST/quality/check
AI quality check on rendered video
POST/publish
Publish video to platforms (YouTube / TikTok / IG)
POST/pipeline/run
Run complete pipeline end-to-end in background
